📥 Télécharger l’appli
Android 7 ou plus récent · environ 3 Mo
1Touche 📥 Télécharger l’appli. Si Chrome te demande, touche Télécharger quand même.
2Ouvre le fichier Calendrier-Celestine.apk (dans la notification ou dans Téléchargements).
3Si Android le demande : Paramètres → active Autoriser cette source, puis reviens en arrière.
4Touche Installer, puis Ouvrir. L’icône 🎄 reste sur ton écran d’accueil.
Un souci ?

• « Appli non installée » : une ancienne version est peut-être déjà là. Ouvre-la depuis l’écran d’accueil : elle se met à jour toute seule.

• Play Protect affiche un avertissement : touche Plus de détails → Installer quand même. L’appli a été faite spécialement pour toi, elle n’est simplement pas sur le Play Store.

• Ta progression est enregistrée dans l’appli. Si tu avais déjà joué dans le navigateur, ouvre Trésors → 📥 Coller un code dans l’appli.
